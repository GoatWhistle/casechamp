# Атлас связности

Фронтенд исследования транспортной доступности: карта, сезонные фильтры, карточки маршрутов с источниками, сравнение покрытия регионов и справочник индексов. React / Vinext, SVG-карта без платных ключей и внешнего тайлового сервиса.

## Запуск

```sh
npm run dev
```

## Данные

`public/atlas.json` экспортирован из CSV текущего репозитория: 82 региона, 155 412 населённых пунктов в исходной выборке и 997 записей дополнительных связей. Для карты сохранены координаты конечных пунктов и крупнейших поселений. Обычные дороги и магистральные железнодорожные линии не включены.

Из корня этого фронтенда обновить выгрузку:

```sh
python3 scripts/export-atlas.py
```

Путь к родительскому репозиторию определяется относительно экспортера. При переносе фронтенда в отдельный репозиторий нужно сохранить готовую выгрузку или изменить путь `root` в экспортере.

Линии на карте — соединения реальных конечных точек, а не геометрия трасс. Времена поездок не выдумываются. Связи без координат обоих пунктов остаются в выгрузке, но не отображаются на карте. Режим «Все» включает записи с неизвестным сезоном. Точность расписания и дата указаны в карточке источника.

Карточки индексов показывают сохранённую сводку по РФ из `docs/indices.md`, а не значения выбранного региона. Региональные результаты DuckDB отсутствуют в исходной рабочей копии. В таблице такие значения отмечены «Не подключён».

## Картография

Подложка и реки: Natural Earth, public domain. Исходные файлы `ne_50m_admin_0_countries.geojson` и `ne_50m_rivers_lake_centerlines.geojson` из https://github.com/nvkelso/natural-earth-vector. География поставляется локально в `public/geo/`.

## Проверка и сборка

```sh
npx tsc --noEmit
node --experimental-strip-types --test tests/additional-model.test.mjs
npm run build
```

Дизайн: тёплая бумага #f6f5f4, белые поверхности, тонкие границы, без теней и градиентов. Основное действие — #0075de. Есть адаптация для узкого экрана, управление клавиатурой и режим reduced motion.

## Россия → регион → маршрут

Стартовый экран — карта регионов России. Цвет соответствует Hansen, штриховка — отсутствию расчёта. Наведение показывает карточку, клик открывает регион с реальными связями. Выбор доступен также через поиск и клавиатуру.

Подключить существующую DuckDB без пересчёта:

```sh
python scripts/export-indices.py /absolute/path/to/casechamp.duckdb
```

Экспортер запускается в окружении ETL с `duckdb`. `public/indices.json` содержит массив `{ "region_id": "98000000", "season": "road", "hansen_idx": 42.5 }` (значение здесь — только пример формата). В приложении также есть временный импорт такого JSON; он не сохраняется после перезагрузки. Нулевое значение отличается от отсутствующего. Дубликаты региона/сезона и некорректные числа отклоняются.

Границы регионов: Click That Hood, OpenStreetMap, снимок 2013 года. https://github.com/codeforamerica/click_that_hood/blob/master/public/data/russia.geojson. Сохраняются исходные границы, используется коническая проекция Ламберта. 81 из 82 регионов выборки сопоставлены с геометрией. Крым остаётся доступен через поиск и таблицу, но отсутствует в этой архивной подложке; Москва и Санкт-Петербург показаны вне выборки. Ограничение видно в пояснении карты. Подготовка геометрии: `python3 scripts/prepare-regions.py`.

## Экономика и сезонные наблюдения

Новые данные формируются из корня родительского проекта командой `uv run python etl/additional_data.py`.
Для повторной сборки необходимы приобретённые исходники в `data/additional/`; сам сайт работает
на готовых агрегатах, не требует доступа к локальному DuckDB и не публикует ИНН компаний.

`public/additional.json` содержит региональные и отраслевые агрегаты, каталог восьми источников,
18 записей девяти зимников Югры за два сезона, расписание КАП и транспортные таблицы с источниками.
`public/additional/regions/<ОКТМО>.json` загружается при выборе региона; 82 файла охватывают
155 412 населённых пунктов с населением, привязанными компаниями и освещённостью двух лет.

Срез RFSD за 2025 год: 3 143 178 строк, из них 2 230 505 в географии атласа; остальные 912 673
не включены в его итоги. 1 808 061 запись сопоставлена с ФНС по ИНН без размножения строк.
Фильтр качества: `filed=1`, `eligible=1`, `imputed=0`, `outlier=0`, точность адреса `house/street`,
валидные координаты. В 82 регионах прошли фильтр 1 338 165 компаний, из них 1 059 849 с выручкой.
1 190 422 компании однозначно связаны с ближайшим НП своего региона в пределах 5 км.
Выручка RFSD переведена из тысяч рублей в рубли; доход ФНС хранится отдельно и не подставляется
в пропуски выручки. Неизвестное значение отличается от нуля. Карта показывает все отрасли;
отраслевой фильтр применяется к KPI и таблице сравнения. ФНС, освещённость и таблица НП относятся
ко всем отраслям, что подписано в интерфейсе.

Сезонный модуль проверяет дату и ограничение массы по опубликованным наблюдениям. За пределами
периода наблюдения показывает отсутствие данных. Сценарий круглогодичной связи — обозначенное
допущение, без утверждения об изменении Hansen, населении зависимой территории или стоимости.
Расписание КАП учитывает дни недели, интервалы, отдельные даты и смену года; фактическое
выполнение рейсов не оценивается. События МЧС, северный завоз и натурные обследования доступны
в выгрузке исходных транспортных таблиц, но не становятся рёбрами графа автоматически.

Экономический Hansen не отображается как рассчитанный: в этой рабочей копии отсутствуют
транспортный граф и сохранённые времена поездки. В `additional.json` это статус
`economic_access.status = missing_transport_graph`. Карта компаний, выручки и освещённости
показывает исходные показатели, а не доступность рынков.
