# Национальные объекты доступности

Сохранённые JSONL-снимки девяти OSM-выгрузок с координатами, тегами, версиями объектов, пространственной привязкой к 84 территориям и происхождением. Исходные URL, даты и SHA256 — в `sources.json`; контрольные суммы каждого сжатого датасета — в `manifest.json`.

Объекты не равны уникальным учреждениям: пересекающиеся выгрузки могут содержать одинаковый OSM-ID, а организация — несколько объектов. При импорте используется идентификатор объекта. Полнота каталога, медицинские профили и действующий статус учреждений не подтверждены.

Импорт существующим конвейером при настроенных переменных ClickHouse:

```sh
backend/.venv/bin/python etl/import_national_inventory.py --root datasets/normative-national --district central_federal_district
```

Повторить для остальных идентификаторов из `sources.json`.

Результаты по муниципалитетам находятся в соседнем `municipal-indices/`. Пешеходные и автомобильные графы сохраняются отдельно в локальном архиве; этот небольшой набор объектов не подменяет графы маршрутизации.
