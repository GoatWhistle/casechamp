# Индексы доступности муниципалитетов

Датасет содержит исходные измерения N01–N09 и результаты пространственной агрегации по сохранённым границам. Региональные проценты не используются вместо муниципальных.

## Состав

- `sources/<sha256>/`: исходные результаты маршрутизации по точкам, объекты и параметры расчёта в манифесте, сжатые JSONL и контрольные суммы.
- `boundaries/<sha256>/`: исходные муниципальные полигоны и их происхождение.
- `aggregates/`: значения, знаменатели, выбранные точки, хеши источника, границ и методики.
- `municipal-indices.jsonl.gz` и манифест: переносимая выгрузка агрегатов и перечень необходимых исходных снимков.
- `batch-progress.json`: последний выполненный проход. Завершение прохода не означает наличие данных по каждому показателю; проверяйте статусы записей.

Медицинские значения описывают физическую доступность известных объектов, без подтверждения специализированного профиля. Школьные значения рассчитаны по опорным жилым точкам, не по числу детей. Для пожарного сценария сохранено предположение40км/ч и пороги10/20мин; это не измеренное время реагирования.

## Повторный расчёт

При настроенных переменных ClickHouse выполнить из корня репозитория:

```sh
backend/.venv/bin/python etl/aggregate_municipal_measurements.py --output datasets/municipal-indices --export datasets/municipal-indices/municipal-indices.jsonl.gz
```

`--regions` ограничивает регионы, `--criteria` — показатели. Повторный запуск использует неизменные исходные измерения; изменения границ или методики создают новую агрегацию. Изменение дорог требует нового расчёта маршрутов.

## Исходная сеть

Национальные исходники, объекты и манифесты сохраняются в `.local/normative-national-inputs/`; региональные пешеходные сети — в `.local/normative-regional-walking/networks/`. Эти локальные бинарные данные не следует считать присутствующими в Git только по наличию отчёта.

`road-network/` содержит независимый сжатый снимок таблиц дорожной сети в формате ClickHouse Native. Его SHA256, DDL и число строк записаны в манифест. Восстановление выполняется существующим `etl/analytics/restore_snapshot.py` в пустые таблицы; исходная база не перезаписывается.

Полнота национального покрытия определяется фактическими манифестами и статусами. Отсутствующие объекты или пути не подменяются нулевыми индексами.
