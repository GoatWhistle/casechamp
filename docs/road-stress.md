# Что меняется при перекрытии дороги по всей стране

Стресс-тест проверяет все населённые пункты текущего снимка. Он показывает потерянные направления к городам-рынкам, задержки и маршруты объезда. Численность жителей затронутых пунктов описывает охват изменения доступности, а не поток по закрытой дороге.

Связано: [дорожные сценарии](road-analysis.md), [API](api.md), [результаты проверки](results/road-stress-checks.json).

## Как запустить и прочитать сценарий

На карте выберите участки, откройте вкладку «Сценарий» и карточку «Стресс-тест дорог». Закрытие сохраняется как отдельное задание. Кнопка «Добавить к закрытию» объединяет выбранные участки с предыдущими. История и ссылка со значением `stress` возвращают сохранённый результат после перезагрузки.

Результат открывается по регионам. При приближении карта загружает до 200 затронутых пунктов в видимой области. Таблица показывает по 10 пунктов на странице. Клик по пункту открывает его последствия и выбирает его началом маршрута. В форме «Сравнить маршрут» выберите оба конца по названию. Красный пунктир обозначает закрытые участки, серый пунктир исходный путь, синяя линия объезд.

Агент вызывает тот же расчёт через `stress_test_roads`, читает состояние через `inspect_road_stress_test` и строит объезд через `compare_stress_route`. Он получает выбранные дороги, активный сценарий и выбранный населённый пункт. Инструменты возвращают карточки в чат. Проверены их контракты и события; качество ответа платной модели отдельно не оценивалось.

## Что именно считается

| Правило | Реализация |
| --- | --- |
| Охват | 155 747 уникальных пунктов из `plexus_graph.locations`, 84 региона источника |
| Направления | 180 городов-рынков текущего графа |
| Сеть | Круглогодичные автомобильные рёбра снимка, без пассажирских ЖД и авиации |
| Перекрытие | Целые выбранные OSM ways, в обе стороны; параллельные незакрытые ways сохраняются |
| Затронутый пункт | Потеря хотя бы одного ранее доступного внешнего рынка или задержка не меньше минуты |
| Задержка | Наибольшая разница кратчайших времён среди оставшихся доступных рынков |
| Потеря внешних рынков | До закрытия был хотя бы один внешний рынок, после не осталось ни одного; собственный город исключён |
| Пробелы данных | Пункты без дорожной привязки и исходно недоступные внешние рынки считаются отдельно |
| Объезд | Самый быстрый путь по графу; километры суммируются по рёбрам именно этого пути |

Порог 72 часа не применяется. Перед расчётом времён проверяются компоненты связности. Таблица изменений направлений содержит время по графу без подъезда к нему. В явном маршруте между двумя пунктами подъезды добавляются по расстоянию привязки со скоростью 15 км/ч.

Сезонный переключатель атласа не меняет этот стресс-тест: он использует круглогодичную дорожную сеть. Направления движения упрощены, фактическая проходимость, грузовые ограничения и дорожный трафик не подтверждены. Потеря всех модельных рынков не доказывает полную физическую изоляцию поселения.

## Что подтверждено локальными прогонами

Измерено 11 ноября 2026 года, граф `road-8033092fca2cf5fa`, 6 вычислительных воркеров. Гипотеза проверки: национальные и совместные закрытия завершаются на текущем наборе, сохраняются в ClickHouse и дают неулучшающиеся времена пути.

| Закрытие | Время прогона | Новая потеря всех внешних рынков |
| --- | ---: | ---: |
| М-10 целиком, 2 454 ways | 212,4 с | 169 пунктов |
| М-10 и М-11, 4 070 ways | 284,1 с | 173 пункта |
| Р-257 целиком, 534 ways | 283,6 с | 98 пунктов |

Во всех трёх случаях хотя бы одно направление изменилось у 154 899 пунктов в 82 регионах. Это 127 754 656 жителей. Совпадение общего охвата не означает равный ущерб: задержки, потерянные направления и новая изоляция различаются. Такой чувствительный критерий нельзя использовать как оценку числа пользователей трассы.

Негативный контроль: закрытие одного way М-10 с ID `4412349` не дало потерь рынков или задержек от минуты. Первый прогон с построением базовой матрицы занял 248,6 с. В снимке 483 пункта без дорожной привязки; ещё 77 привязанных пунктов исходно не имели внешнего рынка.

Маршрут Торжок–Великий Новгород при закрытии М-10 изменился с 337,03 км и 4,194 ч до 429,37 км и 5,626 ч. Геометрия получена из найденных путей. Проверены параллельные дороги, путь дольше 72 часов, исключение собственного рынка, отмена очереди и восстановление результатов после перезапуска API.

Каждый национальный сценарий измерен один раз на локальной машине при параллельной нагрузке. Эти наблюдения не устанавливают гарантированную задержку ответа. Первый объезд может строиться долго; повтор той же пары в процессе обслуживается из ограниченного кеша. Национальная матрица исходных времён сохраняется в ClickHouse, изменённая сеть пересчитывается полностью.

## Как повторить расчёт и подготовить хранилище

В Compose сервис `stress-schema` применяет добавочную схему перед backend. Для уже запущенного локального ClickHouse:

```sh
set -a
source .env.analytics
set +a
PYTHONPATH=backend/src backend/.venv/bin/python backend/scripts/migrate_road_stress.py
PYTHONPATH=backend/src backend/.venv/bin/python backend/scripts/verify_road_stress.py --reference М-10 --output /tmp/stress-m10.json
```

API по умолчанию: `http://127.0.0.1:8817`; другой адрес задаётся через `--api`. Для совместного закрытия передайте `--reference М-11 --parent <id предыдущего задания>`. Уже завершённый идентичный сценарий возвращается из истории; время такого запроса не является повторным вычислительным замером.

Задания и сводки лежат в `stress_jobs`, детали по пунктам и направлениям в `stress_point_impacts`, исходные числовые массивы в `stress_baseline`. Ключ базового кеша включает версию графа, метод, порядок пунктов, их узлы и рынки. После смены графа сохранённая сводка читается, но геометрия и новый маршрут по старому заданию отклоняются. Прерванные при остановке процесса задания восстанавливаются как отменённые.

## Краткая сводка перекрытия

В карточке сначала показаны пункты, потерявшие все внешние рынки, их население,
максимальная конечная задержка и жители затронутых пунктов. Список территории содержит
только регионы с изменениями; «Все затронутые» объединяет их. Подробности по пунктам,
маршрут и методика раскрываются отдельно. Старый результат Hansen находится в разделе
«Дополнительно: индекс доступности».

`GET /api/v1/road-stress-tests/{id}/summary?region=...` возвращает общую для UI и агента
сводку. `totals=null` означает незавершённый расчёт, а нулевые показатели завершённого
расчёта означают отсутствие найденных последствий. `region` фильтрует итоги;
показатели покрытия снимка остаются национальными. Значения агрегируются по всем
сохранённым пунктам, независимо от страницы списка.

Агент по умолчанию вызывает `calculate_scenario(kind=close_selection, assessment=impact)`.
`assessment=impact` в чате также запускает Хансен для регионов выбранных коридоров;
`assessment=hansen` оставляет только региональный индекс.
`inspect_road_stress_test` возвращает сводку и до пяти примеров без массивов OSM ID и
всех направлений. Геометрия остаётся в интерактивной карточке. Эти времена используют
фиксированные веса дорог и не моделируют очереди; сценарий с нагрузкой на объезды
рассчитывается отдельно через связность выбранных населённых пунктов.

Для сохранённого перекрытия 714 ways (`95c3a442bf544d118fac5403cf80eede`) проверка
11 ноября 2026 года подтвердила в Новгородской области 64 пункта и 1 414 жителей,
потерявших все внешние рынки; максимальная конечная задержка — 207,307 минуты.
Это проверка выдачи сохранённого расчёта, а не новый национальный прогон.

## Что именно изменится в регионе

Сводка завершённого сценария с заданным `region` содержит `consequences`.
Регион можно передать точным названием атласа или его ID. Неизвестное название
вызывает ошибку, а не нулевой ущерб. Расчёт использует все сохранённые последствия
в регионе, независимо от страницы примеров. Для незавершённой работы или сводки
без выбранного региона это поле равно `null`.

| Показатель | Что считается |
| --- | --- |
| Потерянные связи | Пары «населённый пункт — внешний модельный город», ранее имевшие дорожный путь |
| Охват задержек от 30, 60 и 120 минут | Пункты, у которых хотя бы одно сохранившееся направление задерживается на заданное время, и их жители |
| Ближние связи | Изменившиеся направления, занимавшие до двух часов до закрытия |
| Среднее время ближних связей до и после | Одна и та же выборка сохранившихся ухудшившихся направлений; равный вес каждого направления |
| Выход за два часа | Ранее ближние направления, ставшие дольше двух часов или недоступными; отдельно число пунктов и жителей |
| Затронутые города | До пяти городов назначения с числом затронутых пунктов, жителей и потерянных направлений |
| Примеры | До трёх потерянных и трёх замедлившихся направлений с названиями и временем до/после |

Пороговые группы вложены друг в друга: их нельзя складывать. Жители считаются
один раз в пределах показателя, но могут повторяться между показателями и городами
назначения. Это охват изменения доступности, а не количество поездок.
Потерянные направления не входят в среднее время сохранившихся маршрутов:
они показаны отдельно, без замены бесконечного времени нулём. Число наблюдений
`comparable_connections` сопровождает среднее. Это **не среднее время поездки
всех жителей региона**.

Сохранённые детали включают потерю пути и конечные задержки от одной минуты.
Поэтому небольшой переход через двухчасовую границу с задержкой меньше минуты
может отсутствовать в отчёте. Два часа — аналитический порог этого отчёта,
а не норматив транспортной доступности. Времена относятся к графу без подъездов.

Агент должен начинать с конкретного последствия, давать сравнение до/после и
один-два примера. Например: «Поездки по направлению Крестцы — Великий Новгород
в этом сценарии удлиняются с 83 до 282 минут; доставки, использующие тот же путь,
потребуют более длинного объезда». Вторая часть — условное следствие изменения
маршрута, а не наблюдение за грузопотоком. Закрытие предприятий, недоступность
больниц, объёмы поставок и потери ВРП требуют отдельных данных.

Это сценарный прогноз дорожной сети при точном сохранённом наборе перекрытий.
Он не добавляет пробки, сезонные связи, ЖД и авиацию. Для модели нагрузки на
конкретные объезды используется отдельный расчёт выбранных населённых пунктов.

Проверка 11 ноября 2026 года на сохранённом перекрытии 714 ways
`95c3a442bf544d118fac5403cf80eede`:

- Новгородская область: задержка от часа хотя бы на одном направлении у
  800 пунктов с 76 600 жителями; 222 сохранившиеся ухудшившиеся ближние связи
  меняются в среднем с 92,19 до 145,19 минуты. Ещё 49 ближних связей теряют путь.
- Тверская область: соответствующий охват задержек от часа — 291 пункт и
  32 029 жителей; 171 сохранившаяся ухудшившаяся ближняя связь меняется
  с 98,84 до 137,70 минуты. Ещё 26 ближних связей теряют путь.

Это один сценарий в двух регионах, а не оценка всех закрытий М-10/М-11.
Независимое суммирование записей по всем 3713 и 8834 затронутым пунктам
подтвердило агрегаты. [Протокол](results/regional-consequences-validation.json)
содержит версии, выборки, определения и конкретные направления.

## Проверка привязки населённого пункта

Перед расчётом перекрытия проверяется случай, когда от городской сети отрезается
только небольшая компонента с точкой привязки населённого пункта. Если рядом
сохраняется связная сеть улиц с циклом, потеря этой точки не подтверждает изоляцию
всех жителей. Такой расчёт отклоняется с `settlement_attachment_conflict`, без
подстановки нулевого ущерба и без добавления искусственного объезда.

Проверка рассматривает существующие всесезонные дороги в пределах750м: исходная
компонента не менее12вершин, отрезанная часть не более4, сохранившаяся сеть не менее8
с циклом. Это контроль неоднозначной привязки. Он не заменяет распределённые
внутригородские точки доступа и не гарантирует обнаружение всех таких случаев.
Сохранённые рейтинги, предшествующие проверке, больше не считаются совместимыми.
