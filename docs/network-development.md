# Сохранённые дорожные эксперименты

Автоматический поиск новых трасс и пакетов проектов удалён. Генератор гипотез,
обучение CatBoost и временные окна генерации и проверки больше не используются.

Существующие результаты сохранены. `GET /api/v1/traffic-jobs` возвращает историю,
`GET /api/v1/traffic-jobs/{job_id}` возвращает результат. Создание нового поиска
через этот адрес недоступно. Исторические значения описывают прежний расчёт и
не являются текущим состоянием муниципального округа.

Распределение сценарного спроса, расчёт маршрутов, географическая проверка
расширения существующих дорог и вычисление связности сохранены.

Публичное название показателя потенциальной доступности городов:
**Связность с городами**. Формула и внутренние идентификаторы не изменены.

Муниципальная карточка читает опубликованные измерения услуг. Отсутствие
измерений отображается явно; открытие карточки не запускает их расчёт.
