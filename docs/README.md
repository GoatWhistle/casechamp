# Документация Plexus

> Plexus считает, как транспортная сеть связывает населённые пункты России с рынками и услугами, и
> показывает, что изменится для региона, если поменять дорогу, маршрут или расписание. Здесь — как
> запустить продукт, как устроены расчёты, откуда данные и где заканчиваются выводы модели.

**Начните здесь:** [запуск](running.md), затем [муниципальный сценарий](municipal-accessibility.md).
Обзор продукта — [README](../README.md).
