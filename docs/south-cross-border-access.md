# Доступность с учётом учреждений соседних регионов

Для Ставропольского и Краснодарского краёв пересчитаны шесть автомобильных критериев:
медицинские объекты с порогами 60 и 120 минут, МФЦ, центры занятости, библиотеки и автостанции.
Цели выбираются по дорожной достижимости из общего каталога. Административная граница
ограничивает выбор исходных точек и агрегацию, но не поиск учреждения.

## Проверка на сохранённых данных

Сравнение выполнено 13 ноября 2026 года по московскому времени. Для каждого критерия
сопоставлены одинаковые точки на одной версии графа до и после расширения каталога.
Числа ниже показывают точки с меньшим временем пути, а не изменение самой инфраструктуры.

| Объекты | Ставропольский край, 760 точек | Краснодарский край, 1765 точек |
| --- | ---: | ---: |
| Медицинские, каждый из двух порогов | 32 | 44 |
| МФЦ | 170 | 214 |
| Центры занятости | 81 | 257 |
| Библиотеки | 44 | 66 |
| Автостанции | 27 | 41 |

Во всех 12 сравнениях нет увеличения времени и потери ранее найденного маршрута.
Сохранены 468 муниципальных агрегатов: шесть критериев для 33 муниципалитетов Ставрополья
и 45 муниципалитетов Краснодарского края. Две исходные точки Краснодарского края находятся
вне загруженных муниципальных полигонов и не включены в муниципальные агрегаты.

Это физическая доступность известных объектов. Каталог медицинских целей включает ФАПы
и поликлиники; кардиологический профиль и возможность приёма этими расчётами не подтверждены.
Поэтому муниципальная карточка показывает «Медицинские объекты», а смысл двух порогов
и ограничение вынесены в подсказку. Пешеходные услуги и пожарный выезд в этот пересчёт не входят.

[Результаты, версии расчётов, SHA256 прежних снимков и примеры](results/south-cross-border-validation.json).

## Воспроизведение

На локальном API с настроенным национальным графом и актуальным каталогом:

```bash
backend/.venv/bin/python etl/calculate_regional_measurements.py \
  --api http://127.0.0.1:8819/api/v1 \
  --regions /path/to/regions.json \
  --output /path/to/results.json \
  --criteria N01 N02 N05 N06 N07 N08 \
  --required-model-revision regional-road-cross-border-v2 --resume
```

Файл регионов содержит объект `regions` с элементами `id` и `name`; идентификаторы краёв
`07000000` и `03000000`. Продолжение задания принимает только результаты указанной версии.
Пустой локальный каталог не исключает автомобильный расчёт: учреждение может находиться
в другом регионе. Для экспорта агрегатов используется `etl/aggregate_municipal_measurements.py`.
