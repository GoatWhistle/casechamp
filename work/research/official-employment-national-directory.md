## Выбор территории подтверждён

[Публичный скрипт выбора региона](https://trudvsem.ru/assets/infoblocks/region_change/choose-region.js) использует анонимный POST `/iblocks/region_change/change?code=<код региона>`, JSON, затем перезагрузку страницы. GET-параметр `regionCode` не заменяет этот механизм. Успешно воспроизведён штатный запрос без авторизации: ответ 200 `{"code":"SUCCESS"}`, последующий GET `/czn` содержит `window.currentRegionCode="2600000000000"` вместо первоначального 4200000000000. Сохранён ответ `.local/research/employment-national/probe-after.html`. Это положительное подтверждение выбора Ставропольского края, а не предположение по URL.

Использованы urllib CookieJar и TLS с `ssl.create_default_context(cafile=certifi.where())`; проверка сертификата не отключалась. POST повторяет публичный AJAX: `Content-Type: application/json`, `X-Requested-With: XMLHttpRequest`, `Accept: application/json, text/javascript, */*; q=0.01`, `Origin: https://trudvsem.ru`, `Referer: https://trudvsem.ru/czn`, пустое тело/Content-Length0, стандартные Sec-Fetch-заголовки, Connection close. Полученные публичные cookies остаются внутри сессии. Доступ к личным кабинетам/авторизации не использовался.

## Контракт выгрузки

Проектные 84 территории сопоставлены с официальным `window.regionsList` по точному имени и явно сохранённым алиасам, включая Москва/Санкт-Петербург, НенецкийАО/ЯНАО, Кузбасс/Югра и полные названия республик. Сопоставление и исходный список провайдера сохранены отдельно. Дополнительные территории провайдера не добавляются к проектной выборке автоматически.

Для каждой выдачи обязательны: успешный штатный POST выбора; последующий HTTP200 GET; буквальное совпадение `window.currentRegionCode` с запрошенным провайдерским кодом; наличие массива `var data` и корректный JSON-разбор. Только после этого выдача получает статус `verified_selected`. Четыре параллельные сессии имеют независимые CookieJar, внутри каждой POST/GET выполняются последовательно. Ошибки и повторы не подменяют регион значением предыдущего успешного запроса.

Неизменённый HTML сохраняется в `.local/research/employment-national/raw/<project_region_id>.html`. Эти исследовательские оригиналы содержат полную публичную страницу. Продуктовые JSON в `centers/<project_region_id>.json` содержат **только name/address/latitude/longitude**; телефоны, email и прочие контакты не переносятся. Геокоординаты приводятся к числам без геокодирования и ручного исправления; отсутствующие/невалидные значения фиксируются как проблема качества. Не делается утверждение, что координата является входом в здание.

Манифест сохраняет requested/actual provider code, project region ID, source/selection URL, дату получения, HTTP-статус, путь/размер/SHA256 исходного HTML, SHA256 ответа выбора, число записей, путь/SHA256 очищенного JSON и число невалидных координат. В JSON с объектами этих служебных полей нет.

## Ограничения

Получение официальной публичной страницы с проверенным регионом подтверждает происхождение опубликованной выдачи на дату загрузки. Оно не подтверждает полноту государственной сети, актуальность адреса/названия/режима работы каждой записи, отсутствие закрытых филиалов, профиль территориального либо управляющего центра, доступность входа или соответствие конкретному нормативу N06. Неопубликованный объект и пустая выдача не равны отсутствию ЦЗН. Официальные координаты требуют дальнейшей проверки геометрии/качества; режим расчёта и применимость правового основания остаются отдельными.

### Уже обнаруженные проблемы качества первичного справочника

В сохранённых исходных выдачах найдены точные дубли, координаты вне bounding box проектного региона и названия организаций иного/неясного профиля. Примеры из первичного массива карты: Приморский край, Кавалерово/Пластун — longitude13.505766/13.628308; Краснодар, Красная 42 — latitude38.969617/longitude45.021302; Алтайский край — запись управления социальной защиты. Эти примеры показывают, почему подтверждённое происхождение не является подтверждением координат и профиля объекта. Координаты не переставляются и не дополняются угадыванием цифр; несоответствующие кандидаты должны быть исключены из нормативного расчёта либо отдельно проверены, сохранив оригинал и причину. Промежуточные row_index и данные записаны в `quality-flags.json`, итог будет пересчитан после всех 84 регионов.

Браузерный инструмент web.open возвращал 460/ошибку доступа для этого сайта; это ограничение конкретного инструмента. Production urllib со штатным анонимным AJAX и проверенным TLS получил 200 и правильный actualcode. Не использовалось отключениеTLS либо обход авторизации.

### Сжатие и сохранение оригинальных байтов

После первых регионов несжатые HTML давали таймауты; штатный HTTP `Accept-Encoding: gzip` проверен:200, ответ 381106 байт за 5,5 с. Партия продолжена с gzip и контрольным восстановлением уже полученных выдач. Для сжатых ответов оригинальные байты сохраняются как `.html.gz`, их SHA/размер стоят в `raw_path/raw_sha256/raw_bytes`; распакованный для разбора HTML сохраняется отдельно с `decoded_html_path/decoded_html_sha256`. Первые несжатые ответы имеют raw_path `.html`. Это обычное согласование транспортного сжатия, TLS остаётся проверенным, механизм выбора региона тот же. Частичные либо не прошедшие actualcode выдачи не становятся успешными строками.
