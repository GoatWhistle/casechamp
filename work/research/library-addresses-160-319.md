Для неоднозначных карточек и единственной карточки без почтового адреса основной `address` остаётся null. Полные исторические тексты не копировались в артефакт.

## Проверка извлечения

Покрытие и порядок 160 URL точно совпали со срезом индекса; повторов URL нет. У неоднозначных записей и записи без адреса основной адрес null. Все записи имеют дату и явное происхождение даты. Служебные фрагменты тел удалены из выходного JSON.

При обработке обнаружены два технических риска: web reader иногда соединяет ошибку и следующий ответ разделителем без предшествующего переноса строки; разделение только по полным строкам могло бы перепутать URL и чужой адрес. Блоки разделены по самому длинному дефисному разделителю и сопоставлены по собственному `Source: open`. Также адресные строки собираются через переносы без многострочного значения `$`, иначе адрес обрезался бы после первой строки.

Набор не доказывает полноту действующей сети, нормативную допустимость профиля, проверенный вход или актуальность режима обслуживания. `profile_hint` служит предварительной классификацией для проверки, а не юридическим заключением.


## Ошибки прямых URL устранены цепочкой первичного источника

Первоначально 66 прямых открытий URL отвечали внутренней ошибкой инструмента, включая повторное открытие. Это не оказалось недоступностью первичного содержания. Для каждого из них выполнена фактическая цепочка: [корневая карта134](https://yugovalib.ru/site/view/134) → ссылка категории → ссылка страницы пагинации → ссылка карточки с точным совпадением заголовка. Прочитаны 18 категорий и 25 необходимых страниц; все66 заголовков сопоставлены с реальными ссылками. Все66 переходов к карточкам дали собственный H1 и тело. Эти записи имеют `retrieval_method=source_link_chain`; прежние статусы `unavailable` заменены фактическим результатом чтения.

Для [Саратовской карточки3034](https://yugovalib.ru/site/view/3034) выполнено дополнительное открытие внутренней ссылки инструмента: собственный текст сообщает о бывшем детском саде, но не содержит улицы и номера. Это единственный `address_missing`, а не транспортная ошибка. Общий контактный адрес Юговки не использован.

В [Кропанинской карточке5721](https://yugovalib.ru/site/view/5721) фактически прочитаны улица Советская и дом34 без названия населённого пункта; это отмечено, а населённый пункт по названию библиотеки не назначен. Для [Романовской карточки1202](https://yugovalib.ru/site/view/1202) в контактах указан только населённый пункт. Неполный адрес не превращён в точную координату.

[Карандашовская карточка4913](https://yugovalib.ru/site/view/4913) имеет заголовок структурного подразделения без слова «библиотека», но собственное содержание описывает сельскую библиотеку. Предварительный `profile_hint=library` не подменяет последующую проверку допустимости. [Карточка305](https://yugovalib.ru/site/view/305) относится к организации культурно-досугового и библиотечного обслуживания: она отмечена как `other`, отдельно от карточки конкретной Мишкинской библиотеки5707 по тому же адресу.


Дополнительная сверка профилей: карточки4150(Пушкина),4147(Горького)и4146(№24) относятся к именованным общедоступным библиотекам. Упоминание БИС в названии оператора не меняет их профиль на `other`; у всехтрёх`profile_hint=library`. Профиль`other` в этомсрезе оставлен только для туристическогосредства2928, составногоспискаБИС609иорганизации305.
