# Муниципальные индексы и воспроизводимые данные

Запрос: собрать национальные датасеты, рассчитать доступность для каждого муниципалитета и сохранить данные для пересчёта.

## Контракт

- N01–N09: использовать существующие определения, единицы и пороги; не выдавать региональный процент за муниципальный.
- Сохранять объекты, координаты опорных точек, ревизии графов, результаты маршрутизации, границы и агрегаты с SHA256 и датой.
- Точки распределяются пространственно по муниципальным полигонам. Неоднозначные и отсутствующие привязки учитываются отдельно.
- Изменение порогов использует сохранённые стоимости маршрутов. Изменение сети требует нового расчёта по сохранённому графу.
- N03: сценарная скорость 40 км/ч, время оперативного реагирования не подтверждено. Это параметр модели пожарной маршрутизации, не вмешательство по повышению скорости дорог.
- Отсутствие данных не заменяется нулём и не считается завершённым покрытием.
