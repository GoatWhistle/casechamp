# Все комбинации отключений редактируемых связей

9 ноября 2026. Для сохранённого пилотного артефакта `7a33b4bf26cb382c6d765d6e30549e639e94e01c9f4aa9c17111b608f3221d54` перебраны 2⁷ сочетаний включения и отключения семи редактируемых связей отдельно летом и зимой: 256 запросов API к `localhost:8081`. Дорожные рёбра сжатого графа не редактируются и сохраняются. Частоты не менялись.

Независимая реализация Флойда — Уоршелла строит пути по тому же графу, сезонам и правилу ожидания `84/f`. Из 768 сравнений трёх пар с API совпали все: 640 найденных путей (максимальная разница времени 0 ч при допуске 1e-9) и 128 случаев `no_route`. Все случаи отсутствия пути относятся к Сыстыг-Хем — Тоора-Хем: по 64 комбинации на сезон при отключении соответствующей активной сезонной связи. Это отсутствие пути **в рассматриваемом графе**, не доказательство отсутствия реальной поездки.
