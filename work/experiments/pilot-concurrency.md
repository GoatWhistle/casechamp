# Проверка параллельных сценариев пилота

Дата: 2026-11-09, feat/model-validation, HEAD bad747d, незакоммиченные изменения интерфейса. Испытания выполнены на одном локальном процессе Uvicorn с реальными файлами, без сетевой эмуляции или изменения сохранённого графа.

`uv run uvicorn app.main:create_app --factory --host 127.0.0.1 --port 18080` из backend/; затем из корня `python3 work/experiments/pilot_http_concurrency.py`. Последовательные эталоны для восьми разных запросов: лето/зима и частота 2/4/7, зимнее отключение связи и устаревшая версия. Затем 120 запросов из 16 потоков: каждый полный JSON и статус совпали со своим последовательным эталоном; устаревшая версия вернула 409. После испытания GET пилота и SHA-256 файла не изменились. Результаты: pilot-http-concurrency-results.json. Измеренный p95 0,0077 с относится только к локальным запросам конкретного прогона; не показатель пропускной способности, производственного SLA, внешней сети или нескольких процессов.

Браузер: `API_URL=http://127.0.0.1:18080 npx playwright test e2e/pilot-concurrency.spec.ts` из frontend/. Оба desktop-теста прошли: изменение значения при задержанном запросе помечает поздний результат устаревшим; сброс до ответа не возвращает старый результат на экран. Запросы проходят к настоящему API, задержку искусственно задаёт Playwright. Эти два опыта не охватывают все перестановки, сетевые ошибки и много вкладок. Существующий pilot-experiment.spec.ts отдельно проверяет экспорт последнего выполненного результата после изменения формы.

После добавления тестов frontend `npm run verify`: 375 unit tests, 36 checks, сборка прошли. Сервер запущен и остановлен для проверки. Продуктовый код для этого испытания не менялся. Первоначальная попытка создать тест указала путь относительно неправильной папки и завершилась ошибкой до создания файла; тест создан по исправленному пути и успешно запущен.

## Поздняя ошибка после сброса

9 ноября 2026: `E2E_BASE_URL=http://localhost:8081 npx playwright test e2e/pilot-concurrency.spec.ts` — 3 passed, desktop Chromium. Новый сценарий задерживает ответ POST, сбрасывает форму, затем возвращает искусственный 503. Ошибка и старый результат не появляются, исходная частота восстанавливается; следующий реальный расчёт проходит. Biome для тестового файла прошёл. Первая версия сценария была прервана, поскольку тестовая подмена ошибочно оставалась включённой для следующего запроса; после её снятия весь набор прошёл. Это не проверка всех вариантов параллельности. Черновой ZIP предшествует этой правке теста.
