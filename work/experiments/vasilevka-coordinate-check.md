# Возможная перестановка координат двух Васильевок

В исходном parquet `data_allsettlements_anon_156_v20260925.parquet` и `stg_settlements` присутствуют две одноимённые деревни Залегощенского района:

| ОКТМО | Муниципалитет | Население | Координата входа |
| --- | --- | ---: | --- |
| 54618416111 | Ломовское | 0 | 52.882222, 36.928333 |
| 54618422101 | Нижнезалегощенское | 517 | 52.794444, 36.691111 |

Расстояние между входными координатами 18,686 км. В локальном OSM-срезе есть две точки с названием Васильевка: village 1426095425 (52.8830005, 36.9279221) и locality 1426065418 (52.79385, 36.68985). Отсутствие ОКТМО в тегах этих точек не позволяет назначить код только по OSM. Извлечение: `uv run python work/experiments/orel_place_nodes.py`, результат `orel-place-nodes.json`.

[Районная администрация](https://admzalegosh.ru/article1388) и [закон о муниципалитетах](https://www.orel-gov.ru/doc/663) подтверждают наличие Васильевки в Ломовском поселении и отдельной Васильевки — центра Нижнезалегощенского поселения. [Карта по коду 54618422101](https://geotree.ru/oktmo?title=деревня+Васильевка+%28Орловская+область%2C+Залегощенский+район%2C+поселение+Нижнезалегощенское%2C+54618422101%29) указывает 52.883, 36.9279. Вторичные географические описания также относят координаты 52°47′41″, 36°40′59″ к Ломовской Васильевке. Это сильные признаки перестановки координат в источнике, но точная поправка ещё не утверждена по первичному географическому реестру.

Исходный набор не изменялся. `uv run python work/experiments/vasilevka_coordinate_check.py` воспроизводит две строки и условную чувствительность: замена вклада 517 жителей индексом второй координаты при прежней нормировке увеличивает показатель области на 0,017209 пункта (+0,01205%). Это арифметический сценарий, не пересчёт и не исправленный результат.

Нужна явная таблица поправок с источниками и проверкой исходных значений, затем повторное построение затронутых привязок и экспортов. Нельзя молча менять исходный parquet или объявлять предыдущую привязку через реку доказанной транспортной ошибкой: исходная точка могла относиться к другой деревне.
