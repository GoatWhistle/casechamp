# Противоречивые запросы к API пилота

9 ноября 2026, локальный стенд `localhost:8081`, модель `tuva-frequency-v1`, артефакт `7a33b4bf…`. Скрипт `python3 work/experiments/pilot_api_boundary.py` отправил семь негативных запросов к настоящему API и сравнил исходный расчёт до и после.

Три варианта повторного изменения `manual:0` — включение и отключение в обоих порядках, две разные частоты — отклонены с HTTP 422. Неизвестная связь, изменение нередактируемой дороги и задание частоты зимнику также дали 422. Запрос с устаревшей версией дал 409 `stale_pilot_version`. Базовый ответ после негативных запросов побайтно по структуре JSON равен полученному до них. Результаты с кодами: [pilot-api-boundary.json](pilot-api-boundary.json).

Это семь специально выбранных случаев, не исчерпывающая проверка входов. Независимые unit-тесты домена уже содержат проверку повторов, неизвестных и нередактируемых связей; в этом эксперименте используется работающий HTTP-стенд.
