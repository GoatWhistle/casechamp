# Проверка агрегации национального индекса

Дата: 2026-11-09; ветка feat/model-validation, HEAD bad747d. Входы: data/casechamp.duckdb и frontend/atlas/public/indices.json; расчёт из корня `uv run python work/experiments/national_aggregation_audit.py > work/experiments/national-aggregation-results.json`. Скрипт читает таблицы без записи и независимо агрегирует значения idx_np через numpy; он не пересчитывает граф или формулу Hansen из времён пути.

Проверено 777060 строк НП по пяти сценариям и 410 региональных строк: уникальность (сценарий, point_id) и (сценарий, код региона); совпадение числа НП, суммы населения, числа и населения с хотя бы одним конечным маршрутом; совпадение взвешенного индекса по всем строкам и выгрузки с базой. Наибольшее абсолютное отличие агрегата 9,1e-13 индексных пункта. В каждом сценарии 155412 разных point_id, пропусков и отрицательных значений населения в этой витрине нет; 24758 записей имеют нулевое население в исходном срезе. Это не проверка корректности переписи, адресной привязки или источника численности.

В летней смешанной сети для 1274 из 155412 пунктов, населением 243274 по входному снимку, не найдено ни одного конечного пути к выбранным 180 рынкам. В road — 1988 пунктов, 904559 человек; зимой смешанная сеть — 623 пункта, 97828 человек. Это отсутствие пути в модели, не доказанная изоляция в жизни. Для таких пунктов расчет использует нулевой вклад; региональные суммы сохраняют их население в знаменателе.

Проведён контрастный расчёт: среднее по населению только пунктов, для которых модель нашла хотя бы один рынок, с той же нормировкой. Это не замена индекса и не оценка правильного значения для пропущенных путей. В летнем смешанном сценарии Саха: 5,397 в опубликованном показателе против 5,804 по покрытому населению (+7,56%); Камчатка: 4,347 против 4,653 (+7,05%). Для этих регионов ранги 74 и 76 не меняются. Среди 82 регионов максимальный сдвиг ранга в этой конкретной проверке — одно место (Югра и Республика Алтай). На другие сезоны, меры неопределённости или фактическую доступность этот вывод не переносить. Полный набор — national-aggregation-results.json.

Различие двух средних — следствие выбранных знаменателей, а не исправление ошибок маршрутизации. 180 рынков, реальные расписания, полноценность OSM и валидность агрегирования по административным единицам нуждаются в отдельных проверках. 82 региона исключают неполные территории, поэтому не означают охват всей России.
