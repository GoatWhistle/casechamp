# Проверка подъездов к двум выбранным пунктам

Дата: 2026-11-09, feat/model-validation bad747d. Вход — неизменённые data/osm_ways/{central,northwestern}.parquet (дорожные ways, извлечённые из среза Geofabrik) и data/graph_ru/{points,nodes,edges,ways}.parquet. Команды из корня:

```
uv run python work/experiments/local_road_detour.py central 0.3 > work/experiments/local-road-detour-central.json
uv run python work/experiments/local_road_detour.py northwestern 0.3 > work/experiments/local-road-detour-northwestern.json
```

Скрипт выбирает все дорожные ways, имеющие вершину в рамке вокруг пункта и его национального узла с запасом 0,3 градуса, включает их целиком и строит сеть по совпадающим OSM node ID. Из неё исключены паромы и явно запрещённый доступ; направления одностороннего движения и сезонные ограничения не учитываются. Поиск идёт от ближайшей вершины отобранных дорог к национальному узлу. 0,3 градуса — географическая рамка, а не одинаковая в километрах ширина на широте точки. Длинные ways без вершины внутри рамки могли быть пропущены; дороги за её пределами, пропущенные типы объектов, паромы и неподтверждённые связи не учитываются. Близость к точке населённого пункта сама остаётся приближением. Поиск по вырезке не доказывает отсутствие обхода в реальности.

## Солнечный, Тверская область

Выбрано 2119 дорожных ways и 26591 вершина. Ближайший к координате населённого пункта OSM road node 1407235616 находится на residential way 176118401, в 0,00373 км по прямой; национальная модель привязала пункт к node 2265784196 в 2,610 км по прямой. Местная вырезка не находит дороги между этими узлами даже при игнорировании одностороннего движения; от ближайшего локального узла достижимы 196 вершин вырезки.

Дополнительный контроль **всего сохранённого национального дорожного графа**, а не только вырезки: `uv run python -c` с DuckDB-запросом `select osm_node,node,comp from 'data/graph_ru/nodes.parquet' where osm_node in (1407235616,2265784196)` возвращает компоненты 8562 и 1 соответственно. В компоненте 8562 находятся 53 сжатых узла (`select comp,count(*) from 'data/graph_ru/nodes.parquet' where comp in (8562,1) group by comp`). Компоненты построены по слабой связности на исходном графе; следовательно, эти две вершины не связаны дорогами **в этой модели исходного графа**, даже без учёта направлений. Это сильнее результата локальной вырезки, но остаются неполнота OSM, допущения геометрии и актуальность.

Код graph_russia.py выбирает вершины только крупных компонент (порог 200 до финальной вставки узлов привязки) и соединяет пункт с выбранной вершиной по прямой. Поэтому в данном случае национальный расчёт использует предполагаемый подход к другой компоненте, а не подтверждённый в исходном графе дорожный путь. 53 — размер финальной компоненты; не подменять им отдельно измеренный размер компоненты первого прохода. Отрезок условного подвода пересекает OSM waterway 906802025, как зафиксировано в snap-water-sample.md. Мост, брод, паром или другие способы реального перемещения не проверены. Вывод не доказывает физической изоляции Солнечного и не даёт времени поездки на местности.

## Усадище, Ленинградская область

Выбрано 2951 way и 36004 вершины. Ближайшая локальная дорожная вершина 2378076764 на track way 229180762 находится в 0,8815 км от координаты пункта; национальный узел 9676281092 — в 1,258 км. В выбранной вырезке дорожный путь между ними не найден, достижимы 323 вершины. Ближайшая локальная вершина отсутствует среди сохранённых сжатых узлов национального графа, поэтому компоненты всей сети напрямую по ней не сопоставлены. Выборка не позволяет заключить, что обхода нет во всём графе или на местности.

## Следствие для проекта

Риск не просто в 1–3 км геометрической погрешности: для Солнечного модельный подход соединяет раздельные компоненты и пересекает водоток. Это может завышать доступность по сравнению с сетью, в которой этот подход недоступен, но факт реального завышения и его величина пока не измерены. Не считать данный результат оценкой распространённости по стране и не отбрасывать все привязки длиннее 1 км. Следующая проверка — воспроизводимо отключить только модельный подход в расчёте и оценить, как меняется вклад пункта в показатели региона при сохранении базовой нормировки; отдельно выяснить реальные пути и переправы по первичным данным.
