Команда: запустить backend на 127.0.0.1:18080, затем `cd frontend && API_URL=http://127.0.0.1:18080 npx playwright test e2e/pilot-consistency.spec.ts`.

Проверен только один сценарий; совпадение не подтверждает правильность исходных дорог и расписаний.
