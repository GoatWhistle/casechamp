Одновременно несколько частот и изменения состава графа не перебирались; неизвестная частота альтернатив и применимость исходных данных остаются ограничениями.

## Независимое сопоставление маршрутов

Отдельный скрипт `python3 work/experiments/pilot_frequency_independent.py > work/experiments/pilot-frequency-independent.json` строит матрицу семи вершин и применяет алгоритм Флойда — Уоршелла, тогда как API использует поиск по очереди приоритетов. Это независимая реализация поиска на общей модели, а не независимый источник данных. Проверка не подтверждает реальные условия, корректность самого правила ожидания, граф вне пилота, изменения нескольких связей или сценарии без найденного пути.
