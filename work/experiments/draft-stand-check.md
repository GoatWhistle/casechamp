## Проверка отсутствия внешних зависимостей при работе

На уже собранных образах выполнены две отдельные проверки. Compose запущен с `networks.default.internal: true` и `--no-build`: оба сервиса healthy, попытка backend подключиться к 1.1.1.1:443 вернула `101` (network unreachable), а из frontend-контейнера запросы к главной странице, `/api/v1/health` и `/api/v1/pilots/tuva` прошли. Docker в этой конфигурации не назначил опубликованному порту подключение к хосту (`NetworkSettings.Ports` пуст), поэтому браузерные тесты при таком запуске завершились `ERR_CONNECTION_REFUSED`; это не успешная полная офлайн-проверка.

Затем контейнеры запущены в обычной сети. В Chromium все запросы за пределы localhost принудительно блокировались: карта → пилот Тывы → частота семь → значение 14,24 часа прошли; попыток внешних запросов в этом маршруте не зафиксировано. Проверка не покрывает остальные экраны, внешний доступ контейнеров при втором запуске не был заблокирован, полная офлайн-сборка и объединённая браузерная проверка с изолированным backend не выполнены. Контейнеры остановлены.

## Сквозной пилот при изолированных сервисах

Дополнительный запуск того же черновика использовал уже собранные образы, сеть Compose с `internal: true` и отдельный nginx-прокси с двумя сетевыми интерфейсами для доступа браузера с хоста. Сам frontend и backend подключены только к внутренней сети. Пробное TCP-соединение backend с 1.1.1.1:443 вернуло 101, `nc` во frontend завершился с ошибкой. Прокси принимал запросы с 127.0.0.1:18090 и пересылал их только frontend.

В Chromium перехватывались и блокировались запросы за пределы localhost. [Сценарий](offline_pilot_browser.cjs) прошёл: карта, открытие пилота, расчёт для семи рейсов и отображение 14,24 ч, проверка частоты в выгруженном JSON и сброс до двух рейсов. Попыток внешних запросов браузера не было. Тест проводился на одном сценарии с имеющимися образами, через вспомогательный прокси; он не доказывает работу всех экранов или возможность собрать образы без сети. После проверки прокси и контейнеры удалены.
