# Brand: Plexus

Decision 2026-11-08 by the user: name Plexus («мне нравится plexus»), mark concept «Изохроны», variation 2 «Градация» («градация норм»).

- Wordmark: Onest 700, tracking −2 at size 76, lowercase «plexus», letters #0e1012.
- Rings: 3 offsets of the filled letter outlines (no rings inside counters). Gap 11, step 6.5, line 2.2 at size 76. Colours inner to outer: #0066db, #5c9eea, #b9d5f8. Dark: #5aa6ff to #1d4f8f, letters white. On blue: white to #7fb0ee.
- Small mark: letter x with one ring (gap 7, line 4.4) up to 48 px; three rings from 96 px.
- Files: docs/brand/wordmark-light.svg, wordmark-dark.svg, symbol.svg (classes mark-base, mark-accent). Source: work/brand/export_mark.py (fonttools, uharfbuzz, shapely; run with uv --with).
- Motion: word fades in, rings expand from the letters (scale 0.96 to 1, opacity), staggered; loader pulses the rings.
- Shown in work/design/design-system.html, section «Знак».
- Not done yet: frontend tokens and header, favicons via npm run brand:assets, PRODUCT.md and DESIGN.md.
