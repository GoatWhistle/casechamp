# Региональная доступность услуг

Режим: Operate. Существующая карта, светлая тема, токены Plexus, без новой страницы. Выбор услуги и региона остаётся сверху. Национальный каталог показывает фактические объекты и их источники. Расчёт автомобильной поездки доступен отдельной кнопкой только для поддержанных моделей, без объявления правового соответствия. Школы, остановки и пожарное реагирование не подменяются автомобильной поездкой.

В правой панели: регион, число объектов, краткое различие физического измерения и норматива, рассчитанные пути, выбранная точка, таблица и источники. Подробности и ограничения раскрываются постепенно. Учитываются выбранные закрываемые дороги; исходная и сценарная сеть доступны явно. Сохранённый результат восстанавливается при перезагрузке и никогда не меняет выбранный регион. Маршрут выбранной строки отображается на общей карте.

Состояния: загрузка каталога/снимка; реальный пустой каталог; ошибка с повтором; расчёт с индикатором; сохранённые числа; точка без пути; смена региона без чужих результатов. Никаких процентов нормативного охвата по неквалифицированным объектам. Все подписи из RU-словаря. Проверка в браузере1440/1920; мобильные проверки исключены инструкцией пользователя.


Country overview: normative metrics open in index mode with no forced region. Sortable paginated region table and choropleth share the generated API summary. A region row opens its calculation and legal basis. Null values show the missing-input reason; population and point denominators remain separate. Index/travel/status controls preserve access to physical routes.

Index detail opens without catalog or full route requests. The explicit paths action enables those queries. Kurgan uses the same regional numeric snapshot as the country overview instead of replacing it with the older pilot coverage. Compact cached results require latest-run and full-basis equality.
