# Перенос макетов в приложение

Дата: 2026-11-08. Ветка `feat/frontend`, реализация `96cd7b7`, исходный коммит `a445fa8`.
Область: главная, карта, регионы, карточка региона, зимний календарь, источники и методика.
Визуальные образцы: финальные корневые `index.html` и `tabs-updated.html`, оформление из `design-system.html`.

## Как проверяли

- `cd frontend && npm run verify`: 36 правил, TypeScript, Biome, 369 unit-тестов и production-сборка прошли. Полный вывод: [verify.log](verify.log).
- `E2E_BASE_URL=http://127.0.0.1:5177 npm run e2e -- --grep-invert mobile --workers=2`: 17 тестов прошли, мобильный тест исключён. [e2e.log](e2e.log). Сценарии закреплены в `frontend/e2e/`.
- Реальные данные существующего FastAPI на порту 8011, Vite на 5177. Бэкенд, схема API и данные не изменялись.
- 21 снимок: 7 экранов × 1280/1440/1920 px, высота окна 1000 px. На 1440 снималась вся страница, на остальных ширинах первый экран. Горизонтального переполнения и ошибок JavaScript нет: [результаты 1440](results.json), [остальные размеры](desktop-widths.json).
- Axe на семи экранах 1440 px: 0 нарушений. Отдельный e2e проверяет восемь маршрутов, включая неизвестную страницу, с тегами WCAG 2 A/AA, 2.1 A/AA и 2.2 AA.
- Проверены непрерывные сигналы и повтор главной, reduced motion, стрелки/Home/End вкладок, сохранение темы, раскрытия, смена сезона и немедленный переход, глобальный поиск, сравнение календарей и интерактивная матрица. Регрессионные проверки карты покрывают жесты, фиксацию геометрии, сброс, прерывание движения и совпадение попадания указателя с геометрией.

## Найденные и исправленные сбои

| Сбой | Исправление | Подтверждение |
| --- | --- | --- |
| Колесо над таблицей не прокручивало документ | Явная горизонтальная область прокрутки таблицы | `region table uses document scrolling from inside its rows` |
| Немедленный переход после смены сезона использовал прежний сезон | DOM RouterProvider и синхронное обновление параметра | `region filtering and global search preserve the chosen season` |
| Отложенный фокус страницы закрывал поиск во время ввода | Сохранение фокуса в активном поле | Тот же сценарий быстрого перехода и поиска |
| Пустая тема источников не показывала состояние отсутствия данных | Проверка списка выбранной темы | Проверка исходного кода; на живом наборе все четыре темы непустые |
| Проверки старой карты ожидали её на `/` и автоматический зум | Рабочий маршрут `/map`, проверка сохранения камеры при выборе | Регрессионные e2e карты |

Первый e2e-прогон выявил ошибку прокрутки, следующий выявил устаревший сезон; адресный прогон затем выявил потерю фокуса поиска. Все исправления входят в `96cd7b7`. Временный диагностический скрипт сначала ошибочно искал canvas и сравнивал сбрасываемый transform/viewBox; итоговые тесты используют реальный `data-view`. Эти ранние ошибки инструмента не выданы за ошибки карты.

## Ограничения данных

- Состав связей собирается из существующего детального API регионов, с кешем и шестью параллельными запросами. На проверенном наборе холодная загрузка запрашивает 63 региона; нового агрегирующего эндпоинта нет.
- Наблюдения МЧС и URL исходных PDF отсутствуют в API. Эти части макета не добавлялись. Календарь показывает возвращаемое имя файла, даты и ограничения.
- Полоса до даты отчёта подписана «закрытие неизвестно»; непрерывность работы не утверждается. Агрегатные строки исключены, в проверенном сезоне 9 маршрутов.
- Матрица методики иллюстрирует формулу с параметром полураспада из API; региональный индекс по-прежнему не рассчитан.
- География и маршруты главной являются декоративной схемой. Числа рабочих экранов поступают из существующего API.

## Не проверялось

Мобильные устройства и viewport по прямой инструкции пользователя. Полный запуск `npm run shots` не использовался, поскольку включает мобильные размеры. Не выполнялись платные проверки, изменения и тесты бэкенда, проверка экранным диктором и отдельный профиль кадров.

Лаунчер Impeccable `context`/`detect` не запустился: engine 0.1.14 отсутствует, каталог кеша недоступен для записи. Использованы прямые инструкции навыка, правила репозитория, визуальное ревью и проверки приложения. Это не результат автоматического детектора.

Корневые HTML сохранены локально и исключены из коммитов. Несвязанные изменения двух сессий прототипов не включались. Настройка репозитория активировала локальные hooks; изменения executable-bit не входят в продуктовый коммит.
