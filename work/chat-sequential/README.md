# Последовательный вывод чата

2026-11-11, feat/map-first-ui, HEAD cdb2c2e. Без коммита и push.

Удалены генераторы Markdown из табличных артефактов и эвристическая перестановка
текста ответа. Все типы таблиц остаются в данных/истории, но не создают второй ответ.
Анализ больше не добавляет шаблонные методические пояснения и таблицу поверх интерпретации.

Основной текст завершается до появления дополнительных блоков. Затем общая интерпретация
расчётов (включая scenario events), по очереди анализы, затем графики.
Место карты фиксировано до загрузки геометрии. Статусы, ошибки и кнопки остаются обычным UI.

Проверки: npm run verify, 36 rules, TypeScript, Biome, 469 tests, build passed.

Браузер 1440px, изолированная тестовая история: шаблон отсутствует, ошибок JS нет.

используют общий рендер. Backend и результаты расчётов этим изменением не изменялись.
